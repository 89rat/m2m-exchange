# PROMPTS.md — mining Gemini (or any idea LLM) for growth, truthfully

Division of labor that works: Gemini = idea fountain (mechanisms, breadth,
adversarial imagination) · this repo's build loop = filter + verifier +
builder. Facts, registries, legal, and code come from verified sources, never
from the fountain.

## Preamble — paste into every session first

> Context: I run code402.dev — a non-custodial x402 payments gateway on
> Cloudflare (agents pay per API call in USDC; money settles DIRECT to seller
> wallets, we never hold funds). Operating entity: a small UK company. Hard
> laws you must never violate in any suggestion: (1) never custody funds — no
> float, no rehypothecation; (2) buyers ride free, we monetize sellers only
> (2% take, $29/mo Pro, $750 concierge launches); (3) no fake attestations,
> fabricated proofs, or self-reported reputation; (4) no deception of agents
> or developers — no hidden directives, covert steering, or per-caller price
> discrimination; (5) burn stays under $500/mo. Give me MECHANISMS and
> STRUCTURES, not names of specific registries/companies/standards — I verify
> facts elsewhere.

## The questions, by growth lever

1. **Prospect mining:** 30 categories of API/data where one call is worth
   $1–$500 to an agent but Stripe-style billing isn't worth the setup; per
   category: who owns them, current monetization, one-sentence pitch.
2. **Outreach copy:** 5 variants of a 4-sentence cold message for the $750
   concierge launch, each leading with a different fear/desire.
3. **Offer hardening:** roleplay a skeptical API owner — 10 hardest
   objections in their voice + strongest honest answers + 3 risk-reversal
   structures that involve no custody.
4. **Honest routing physics:** assuming perfectly informed agents and zero
   deception, every mechanism that makes an endpoint the RATIONAL first
   choice; ranked by durability once copied.
5. **Custody-free rebates:** referral incentives paid only from the
   platform's own fee; what levels move routing; where it races to zero.
6. **Trust products:** machine-speed dispute/recourse mechanisms without
   custody; who bears loss; which produces the most valuable proprietary
   dataset over 3 years.
7. **Red team:** attack the platform as fraudulent seller / wash-trading
   referrer / hostile buyer / competitor — 3 profitable attacks each +
   cheapest defenses.
8. **Template pull (T8):** what converts a create-x402-app clone into a live
   listed seller within 30 minutes; 10 features ranked by drop-off prevented.

## Never ask the fountain

- Which registries/marketplaces exist or how to submit (→ DISTRIBUTION.md,
  verified research). It invents these.
- Legal/regulatory questions (→ solicitor, MAINNET.md gate).
- Current volumes, prices, competitor terms (→ the assay's verified numbers).
- Production code (→ the build loop, against real tests).

Meta-rule: ask for the space of possibilities; verify facts here; ship only
what survives the five laws. Everything that survives becomes a LOOPS.md
backlog item with tests behind it.
